# 干涉與繞射互動電子書

高中一年級必修物理「干涉與繞射」單元（3 節課）的線上教材。純靜態網站，可直接以 GitHub Pages 發布，也可下載後離線開啟 `index.html`。

## 架構

| 分項 | 內容 |
|---|---|
| 開始 | 單元首頁、學習地圖、前測 |
| 第1節 波的疊加 | 1-1 預測 → 1-2 疊加原理（分鏡動畫、繩波模擬）→ 1-3 水波干涉 → 1-4 腹線節線與 CER → 1-5 隨堂測驗 |
| 第2節 雙狹縫干涉 | 2-0 修訂 → 2-1 預測 → 2-2 實拍觀察 → 2-3 次波模型與 B/D 判斷 → 2-4 統整 → 2-5 隨堂測驗 |
| 第3節 繞射與薄膜 | 3-0 證據與模型 → 3-1 單狹縫 → 3-2 薄膜 → 3-3 生活應用 → 3-4 波動性論證 → 3-5 隨堂測驗 |
| 總結與延伸 | 單元回顧、後測、延伸資源與延伸學習單 |
| 索引 | 題目與學習單（自動收錄）、模擬與照片、我的學習紀錄 |
| 教師專區（教師版） | 教學指南、三節流程、核心題目卡、雙向細目表、學習困難、AI 追問規範、素材授權、文件對照 |
| 原始文件（教師版） | 10 份開發文件原文 |

## 檔案

```
index.html              頁面框架
assets/app.css          版面與配色（各分項一個辨識色）
assets/core.js          路由、目錄、互動題、追問助手、測驗、去識別化紀錄、題目索引
assets/sims.js          互動模擬與分鏡動畫
assets/quizbank.js      前測、後測、三節隨堂測驗
assets/content-learn.js 學生章節內容
assets/content-teach.js 教師專區與原始文件頁
assets/docs.js          10 份開發文件原文（由 docx 自動轉出）
assets/icons.js         少量操作圖示
assets/photos/          Wikimedia Commons 照片（授權見下）
assets/img/             多模態需求腳本與數位規劃附圖
```

## 修改內容

- 課文、題目、教師提示：編輯 `assets/content-learn.js`、`assets/content-teach.js`。
- 測驗題目與配分：編輯 `assets/quizbank.js`（配分與認知層次需與細目表一致）。
- 修改後把 `index.html` 內的 `?v=5` 版本號加一，避免瀏覽器使用舊快取。

## 學習紀錄與隱私

- 作答只存在學生自己的瀏覽器（localStorage），網站不收集任何資料。
- 學生以老師給的代碼（如 A07）匯出紀錄；系統會擋下看似姓名、email 或長串數字的代碼，並移除作答文字中的 email、手機號碼。
